# Star Velo 1.0

**Star Velo — 轻量级网络测速工具**

Star Velo 1.0 是 Star Velo 项目的初始版本，旨在提供一个简单、轻量的网络测速体验。

### ✨ 主要特点
- 支持真实网络请求测速。
- 提供下载速度测试。
- 尝试获取网络 IP 和运营商信息。
- 采用轻量化网页结构。
- 无需复杂的前端开发环境。

### 🎯 项目目标
让网络测速变得简单直观，为后续版本的功能升级打下基础。

**项目状态：** 初始原型版本，部分网络信息和测速功能受网络环境及服务端支持情况影响。

# Star Velo 2.0

**Star Velo — 全新视觉设计的网络测速工具**

Star Velo 2.0 是 Star Velo 项目的升级版本。在保留轻量化特点的同时，对界面设计和使用体验进行了全面改进。

### ✨ 主要特点
- 全新深色科技风界面。
- 蓝色霓虹视觉效果。
- 支持真实网络请求测速。
- 提供测速历史记录。
- 历史数据保存在本地浏览器。
- 新增首页、历史记录、节点和关于页面。
- 采用 HTML、CSS 和 JavaScript 构建。

### 🚀 版本升级
相比 1.0，2.0 更注重视觉体验、页面布局和功能组织，让 Star Velo 更接近一款完整的网络测速应用。

### 📌 项目说明
目前为轻量级网页原型，可作为 Android WebView 应用的基础。中国大陆测速节点仍需进一步验证和接入。

**项目状态：** 持续开发中。

**关键词：** Star Velo、Speed Test、Network Testing、HTML5、JavaScript、Android
